## 🏜️ About the Sanctuary

**Батаарын өлгий (Cradle of Tarbosaurus Bataar)** is a premier wilderness eco-lodge and paleontological expedition retreat situated at the gates of the world-renowned **Khermen Tsav** in the South Gobi Desert, Mongolia. 

The application serves as the sanctuary's official international guest portal, offering:
- 🦖 **Virtual Paleontological Field Museum & 3D Specimens**: Educational guides on *Tarbosaurus bataar*, *Deinocheirus*, *Therizinosaurus*, and Gobi dinosaurs.
- 🛖 **Luxury Eco-Accommodations**: Interactive showcase of Family Eco Suites, VIP Deluxe Ger Suites, and Standard Eco Cabins.
- 🗺️ **Expedition Itineraries**: Multi-day wilderness journeys tracking the snow leopard in Tost Tosonbumba Range, camel treks in Narandaats, and deep badland exploration.
- 💳 **Intelligent Multi-Currency Booking Engine**: Dynamic price calculation across MNT (₮), USD ($), EUR (€), and JPY (¥).
- 🌐 **6-Language Localization**: Full translation in Mongolian (MN), English (EN), German (DE), Italian (IT), Japanese (JA), and Chinese (ZH).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/bataar-sanctuary.git

# Navigate into project directory
cd bataar-sanctuary

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be live at `http://localhost:3000`.

### Production Build

```bash
# Compile and optimize for production
npm run build

# Preview production build locally
npm run preview
```
